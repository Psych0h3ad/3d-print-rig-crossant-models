Crossant-235 model assets for 3D Print Rig
==========================================

Crossant-235 by Pole Engineering and contributors. Source revision [e9409a087233f3ec95354594fe9b9cd9357b4ac5](https://github.com/Pole-Engineering/Crossant-235/tree/e9409a087233f3ec95354594fe9b9cd9357b4ac5), V0.6 CAD archive.

Model data and derived geometry retain [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/). See [NOTICE](site/NOTICE.txt) for attribution and changes. The selected Leadscrew-Z assembly has 2,177 named parts. All 3,336 geometry buffer views match the original prepared GLB byte for byte; web colors use sRGB-to-linear conversion. Source contacts and reference surfaces are recorded, and the WIP toolhead and chain routing preview are not certified physical fits. The plate is 235 mm; the nominal build area is 220 × 220 × 200 mm.
